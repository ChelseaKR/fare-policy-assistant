Transit Fare Policy Assistant — evaluation

A narrow retrieval assistant for California transit fare policy, wrapped in a public evaluation harness. This is the evidence hub, not the chat interface: the harness is the point, and the assistant exists so it has something to grade.

Try the system being evaluated

The rider-facing assistant is a separate AWS deployment. It answers from dated policy snapshots and links back here to its evaluation evidence.
